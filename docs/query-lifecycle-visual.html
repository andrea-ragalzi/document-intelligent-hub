    What this walkthrough simplifies

    Every scenario uses the same six phases and 22-stage model. Stage 5 includes the pre-parser deterministic decision. A validated exact-evidence result bypasses normal RAG; unsupported, ambiguous, or failed exact cases continue through it. Stage 19 includes the conditional citation-rescue branch.

    Language stages are a teaching grouping: response language is resolved before the history/reformulation decision; retrieval language is detected on the resulting retrieval question. Stage 7 displays both decisions together. Likewise, context IDs are assigned during prompt construction, and evidence validation/citation construction are two views of the same mapping operation.
